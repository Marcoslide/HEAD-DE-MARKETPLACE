# Playbooks Estratégicos (10.K.1)

`marketplace_playbook` — 33 categorias (Discovery→Method R.E.A.L.).
Contrato OBRIGATÓRIO: quando usar + quando NÃO usar + métrica + risco
(+ ponto de parada, pré-requisitos, impacto em margem/operação).
`VERIFIED_OFFICIAL` é recusado — playbook é estratégia, nunca regra de
plataforma. Seleção contextual por praça/tipo/estágio/empresa; playbook
privado de uma empresa não vaza para outra. Seeds PROVISIONAL rotulados
(imagem, lançamento, kit, saturação, objeção, outcome), vários ligados a
princípios do Método R.E.A.L. (Retenção/Emoção/Autoridade/Ação).
