# Funil de Marketplace (10.K.1)

IMPRESSÃO→CLIQUE→VISITA→CARRINHO→COMPRA→PAGAMENTO→PREPARAÇÃO→ENVIO→
ENTREGA→AVALIAÇÃO→RECOMPRA→INDICAÇÃO. `diagnoseFunnel` nunca analisa
venda isolada: pouca impressão → categoria/SEO/relevância; CTR baixo →
imagem/título/preço/frete; conversão baixa → preço/prazo/avaliação/
expectativa; venda alta + margem baixa → "não é falta de demanda; é
estrutura de rentabilidade" (margem REAL com Ads/desconto/frete/comissão/
devolução/avaria); devolução alta → hipótese de expectativa desalinhada.
Saída sempre separa FATO × HIPÓTESE com linguagem honesta.
