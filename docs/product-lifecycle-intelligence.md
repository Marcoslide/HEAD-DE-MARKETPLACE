# Product Lifecycle Intelligence (10.K.1)

`product_lifecycle`: IDEA→RESEARCH→VALIDATION→LAUNCH→EARLY_TRACTION→
GROWING→SCALING→CHAMPION→SATURATING→DECLINING→REPOSITIONING→
DISCONTINUED (histórico auditável). O estágio ALTERA a recomendação
(testado): LAUNCH → oferta clara/imagem/título/primeiras conversões/
devolução; GROWING → novas praças/Ads/kits/margem; SATURATING → renovar
criativo/preço/kit/reposicionar; DECLINING → reduzir investimento/
liquidar com margem controlada/aprender com o ciclo.
